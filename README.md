# OnlyNewGirls.com

Adult creator career, production, audition, and collaboration service website.

## Local Development

1. Install Node.js 20 or newer.
2. Clone the repository.
3. Run `npm install`.
4. Run `npm run dev`.
5. Run `npm run build`.
6. Run `npm run preview`.

## GitHub Pages Deployment

1. Push the completed project to the main branch of `onlynewgirlscom/s`.
2. Open repository Settings.
3. Open Pages.
4. Set the build source to GitHub Actions.
5. Run or wait for the deployment workflow.
6. Enter `onlynewgirls.com` as the custom domain in GitHub Pages settings.
7. Enable HTTPS when GitHub makes the option available.
